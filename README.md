# iamolayemi/homebrew-tap

Homebrew tap for my command-line tools.

```bash
brew install iamolayemi/tap/dustit
```

| Tool | What it does |
|---|---|
| [DustIt](https://github.com/iamolayemi/dustit) | A careful, open-source disk cleaner for macOS, made for developers |

Casks here are updated automatically by GoReleaser when a new version is released.
