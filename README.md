# iamolayemi/homebrew-tap

Homebrew tap for my command-line tools.

```bash
brew install iamolayemi/tap/macclean
```

| Tool | What it does |
|---|---|
| [macclean](https://github.com/iamolayemi/macclean) | A careful, open-source disk cleaner for macOS, made for developers |

Casks here are updated automatically by GoReleaser when a new version is released.
